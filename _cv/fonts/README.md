# Bundled fonts

The unmodified font files make the CV portable. Build with `--font-path fonts`.

- **TeX Gyre Termes 2.004** (regular, italic, bold, bold italic), by Bogusław
  Jackowski and Janusz M. Nowacki. Distributed under the GUST Font License,
  an instance of LPPL 1.3c. See `GUST-FONT-LICENSE.txt`, `LPPL-1.3c.txt`, and
  `README-TeX-Gyre-Termes.txt` for copyright and licensing information.
  Source: <https://www.gust.org.pl/projects/e-foundry/tex-gyre/termes>.
- **Font Awesome 5 Free** (Solid and Brands), by Font Awesome / Fort Awesome.
  Desktop font files are distributed under SIL OFL 1.1; their embedded copyright
  notices are retained. See `Font-Awesome-LICENSE.txt` and `OFL-1.1.txt`.
  Source: <https://github.com/FortAwesome/Font-Awesome/tree/5.15.4>.

These font files were copied from the local TeX Live distribution. No TeX
installation, font installation, or network connection is required to build.
